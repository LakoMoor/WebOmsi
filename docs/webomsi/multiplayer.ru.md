# Мультиплеер в WebOmsi

Три способа играть вместе, все на стартовом экране в разделе **Мультиплеер**:

| | Кто запускает игру | Что нужно | Подходит для |
|---|---|---|---|
| **Публичный список** | тот, кто выставил комнату или сервер | ничего | зайти и поиграть |
| **Комната** (по коду) | *браузер* одного из игроков | ничего: ни сервера, ни установки | друзья, быстрая игра |
| **Сервер** | программа на компьютере | компьютер, который всегда включён | сообщество, постоянное место |

## Присоединиться

1. Откройте **Мультиплеер**. Вкладка **Публичные** показывает открытые сейчас комнаты и серверы (с картой и числом
   игроков); нажмите **Войти**.
2. Или **По коду**: введите код комнаты, который дал друг, или откройте присланную им ссылку (`…/?room=ABC234`).
3. Или **Сервер**: вставьте адрес сервера (`wss://…`).

Список составляют сами хосты, он **не проверяется**: заходите к тем, кому доверяете.

## Создать комнату (без сервера)

1. **Мультиплеер → Создать комнату.** У комнаты появится код.
2. Отметьте **Показывать мою комнату в публичном списке**, если хотите, чтобы её находили незнакомцы, и дайте ей название.
3. Нажмите **Играть** и отправьте друзьям ссылку-приглашение (**Скопировать ссылку**). Пока вы играете, справа вверху висит
   плашка с кодом и числом игроков (нажмите на неё, чтобы снова скопировать ссылку).

Как это работает: ваш браузер и есть сервер. Браузеры игроков соединяются с вашим напрямую (WebRTC); только чтобы открыть
каждое соединение, два браузера передают друг другу несколько сотен байт через бесплатный публичный релей. Игровые данные
через него не идут.

Что учесть:

* **Держите вкладку открытой и видимой.** Браузер замедляет или останавливает фоновую вкладку, и игра останавливается вместе
  с ней. Вынесите игру в отдельное окно.
* Очень строгая сеть (некоторые мобильные и корпоративные) может блокировать прямое соединение; тогда попробуйте сеть
  другого игрока или сервер.
* Мир для всех считает компьютер хоста; телефон как хост слабоват.

## Запустить публичный сервер

Сервер — это игровая программа без окна. Игроки подключаются к нему по WebSocket, который страница может открыть только
через TLS: серверу нужен адрес `wss://`.

### С доменом и Docker (VPS, бесплатная виртуалка Oracle Cloud, Raspberry Pi…)

```sh
git clone https://github.com/LakoMoor/WebOmsi && cd WebOmsi
DOMAIN=play.example.com SERVER_NAME="Мой сервер WebOmsi" \
  docker compose -f deploy/docker-compose.yml up -d --build
```

DNS домена должен указывать на машину; порты 80 и 443 должны быть открыты. Сертификат Caddy получит сам. Контейнер
`announce` выставляет сервер в публичный список. Настройки в compose-файле (`SERVER_NAME`, `SERVER_MOTD`, `MAX_PLAYERS`,
`ADMIN_PASSWORD`). Первая сборка компилирует игру и идёт долго.

### На своём компьютере, через бесплатный туннель

Ни домена, ни открытых портов: туннель Cloudflare даёт адрес `https://….trycloudflare.com`.

```sh
cargo build --release -p omsi-app
tools/public/build.sh                                  # демо-контент
OMSI_TRIMMED_PACK=1 target/release/openomsi --root public-pack --server server.cfg
```

В `server.cfg` поставьте `map = maps/Demo/global.cfg` и `tunnel = 1`; сервер напечатает адрес туннеля. Чтобы попасть в
публичный список, запустите рядом `deploy/announce.sh https://<этот адрес>`. (Адрес меняется при каждом перезапуске туннеля.)

Остальные настройки (карта, время, погода, команды администратора) в [SERVER.md](../SERVER.md).

### Официальные серверы

Список серверов, за которые ручается владелец сайта, задаётся в `web/config.json`:
`"servers": [{ "name": "Мой сервер", "url": "wss://play.example.com/ws" }]`. Они показываются первыми с пометкой
*официальный*.

## Если не подключается

| Сообщение | Что это значит |
|---|---|
| «В этой комнате никто не ответил» | неверный код, хост закрыл игру или его вкладка в фоне |
| «Не удалось соединиться с хозяином» | строгая сеть блокирует прямое соединение |
| «Не удалось связаться с релеем комнат» | бесплатный релей недоступен или заблокирован в вашей сети |
| в «Публичных» пусто | сейчас никто не выставил комнату: создайте свою |
